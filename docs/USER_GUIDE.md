## 🌟 v2.0 進階版最新重大功能一覽 (What's New in v2.0)

在最新的 **v2.0 進階版** 中，工作站迎來了全方位工作流的大改版：

1. ✂️ **非破壞性編曲片段剪輯與局部消音工坊 (Non-destructive Scissors & Clip Mute)**：
   ![片段剪輯與消音視覺](images/stemforge_v2_editing.png)
   - **🖐️ 選取模式 (快捷鍵 1)**：自由點擊波形進行時間軸尋軌與播放。
   - **✂️ 剪刀切分模式 (快捷鍵 2)**：在任意分軌的音訊波形上點擊即可切開片段，毫秒級精確分段，完全不破壞原始底層音訊檔案。
   - **🔇 片段局部消音模式 (快捷鍵 3)**：切分後點擊任意片段即可將該片段「局部消音」，畫布即時渲染斜紋半透明消音遮罩；再次點擊立即取消消音；播放、混音與匯出自動同步生效。
   - **⟲ 重置剪輯**：一鍵還原所有分軌之裁切片段與消音設定。

2. 💾 **雙重專案持久化管理（Save State & Save As）**：
   - **💾 儲存專案 (快捷鍵 `Ctrl + S`)**：隨時將當前工程之推桿音量、Pan 聲相、Solo/Mute、裁切斷點與局部消音片段即時寫入專案狀態檔。
   - **📑 另存新專案**：支援自訂命名另存為全新工程副本，底層音訊與波形快取直接複用零等待，回載 100% 還原消音片段。

3. 🎧 **音源載入前即時試聽播放器 (Source Pre-listen Player)**：
   - 左側音源區塊內建即時音訊試聽迷你播放器。
   - 支援拖曳/選檔（`blob:` 即時快取）與本機絕對路徑（`/api/preview/local-file` HTTP 206 串流）。
   - 在啟動耗時的分離運算前，可先按下播放鍵預聽音訊是否正確無誤，避免選錯檔案。

4. ☑️ **混音台工具列「全選 / 全清」快速鍵**：
   - 工具列首位配置「☑️ 全選」與「⬜ 全清」按鈕，垂直對齊下方音軌的勾選框，一鍵全勾或全消。

5. 🎼 **原曲調性智慧自動辨識 & 多軌 Phase-Vocoder 高保真變調 ($\pm 6$ 半音)**：  
   - 音訊載入與分析完成後，系統自動以 12 音級 Chroma 特徵矩陣與 Krumhansl-Schmuckler 演算法比對 24 種大小調，即時於 Master 控制列呈現歌曲原調（例如：`D 大調 (D Major)`）。
   - 支援 $\pm 6$ 個半音自由升降，拉動拉桿即時預覽目標調性（例如：`目標: G 大調 (G Major) [-5]`）。
   - 點擊「`⚡ 套用變調`」後正式調度 4 執行緒 Phase-Vocoder 變調演算器；鼓組軌道 100% 自動 Bypass 保留原始衝擊力道，人聲與樂器鎖定共振峰高保真變調。

6. ⏱️ **時間軸拍速智慧偵測與 21 軌無損時間拉伸 (Tempo / BPM Stretch)**：
   - 動態偵測原曲 BPM，支援 50 ~ 220 BPM 自由調整，變速不變調。

7. 🌫️ **混音台處理中半透明變暗遮罩 (Busy Dimming Overlay)**：  
   - 執行神經變調、時間拉伸、深度分軌、載入歷史專案或合併匯出時，下方混音台自動淡入 84% 變暗與 5px 高斯模糊遮罩，中央呈現質感 AI 旋轉流光光環與實時進度，防誤觸並提供清楚狀態反饋。

8. 🎬 **支援 MP4 / MKV / MOV 等影片直接拖入分軌 (Universal Video Demuxing)**：  
   - 直接將 MV、YouTube 抓下的 MP4、或演唱會錄影拖進瀏覽器，系統自動透過本機 FFmpeg 無損抽取 44.1kHz 32-bit Float 雙聲道音訊，直接進行 19+ 軌深度分離。

9. 🎛️ **已勾選音軌即時合併匯出 (Instant Submix / Mixdown)**：  
   - 在多軌混音台勾選任意組合（例如：KTV 伴唱帶、去主唱、或純節奏組），一鍵點擊 **「🎚️ 合併匯出 WAV」** 或 **「🎵 合併匯出 MP3」**，以 C# SIMD 平行累加，瞬間生成混音檔案！

## 1. 第一步：啟動工作站與硬體感知

### 1.1 啟動方式
解壓縮 `StemForge_v2.0.0_Portable_Win64.zip` 後，資料夾內包含以下重要檔案：

```text
StemForge_v2.0.0_Portable_Win64/
├── Start_StemForge_Studio.bat    <-- 雙擊這個啟動工作站！
├── StemForge.Web.exe             <-- .NET 9.0 高效能後端
├── ai_engine/                    <-- Python AI 深度學習推理腳本
│   ├── stemforge_cli.py
│   ├── requirements.txt
│   └── setup_ai_env.ps1
└── wwwroot/                      <-- 現代化多軌 DAW 網頁界面
```

直接雙擊 **`Start_StemForge_Studio.bat`**，系統將在 2 秒後自動打開瀏覽器並連線至：  
👉 `http://localhost:5188`

### 1.2 頂部硬體狀態列
主畫面最上方會即時顯示當前硬體感知數據：
* **GPU 型號**：例如 `NVIDIA GeForce RTX 4050 Laptop GPU`。若無獨顯則自動降級為純 CPU SIMD 模式。
* **VRAM 用量**：例如 `266 / 6141 MB`。**推論完成後自動 100% 物理釋放顯存**。
* **磁碟可用容量**：隨時監控剩餘磁碟空間。
* **狀態指示**：顯示 `AI GPU + C# SIMD Ready` 代表推論環境隨時待命。

## 2. 第二步：音源載入與即時試聽

### 2.1 支援檔案格式
* **一般音訊**：`MP3`, `WAV` (支援 16/24/32-bit Float), `FLAC`, `M4A`, `OGG`。
* **影片容器支援**：`MP4`, `MKV`, `MOV`, `M4V`, `WEBM`, `AVI`。

### 2.2 兩種載入操作方式
1. **拖曳上傳**：  
   直接將音樂或影片檔案由檔案總管拖曳至左側深藍色虛線區塊 **「點擊選擇或拖曳音樂檔案至此」**。
2. **本機絕對路徑輸入**：  
   在輸入框直接填寫路徑（例如：`D:\Music\live_concert.mp4`），按下「🚀 開始精細分軌」，系統直接在本機讀取，跳過瀏覽器上傳等待。

### 2.3 🎧 音源即時試聽 (Pre-listen)
載入音源後，下方會立即彈出迷你試聽播放器：
* 點擊 **▶ 播放** 可直接在網頁試聽音訊片段。
* 隨時確認音訊版本、開頭是否乾淨無誤，再點擊「🚀 開始精細分軌」，避免誤選耗費 GPU 時間。

## 3. 第三步：四大分離與能量守恆模式選擇

在左側面板「2. 分離與相位守恆模式」下拉選單中，可依據您的使用目的隨時切換：

| 模式名稱 | 演算法核心 | 最佳使用場合 |
| :--- | :--- | :--- |
| **BitAccurateResidual** *(預設)* | 殘差公式：$Residual = Mix - \sum Stems$<br>生成獨立第 19 軌殘差，Null Test 誤差達 **`-140 dBFS`**。 | 專業母帶級母帶後製、極限音質追求者。 |
| **BitAccurateProportional** | 將殘差按各子軌瞬態能量比例回填，維持 100% 能量守恆且不需多一軌殘差。 | 遊戲配樂 Remix、Podcast 訪談清晰化。 |
| **PureIsolation** | 啟用軟性頻譜包絡閘門（Soft Spectral Gate），徹底消除樂器靜音區間的微弱漏音。 | 扒帶、樂器抓譜、單獨聽特定樂器演奏。 |
| **AiTrainingDry** | 極致去除空間尾音殘響、濾除超低頻直流偏移（DC Offset），峰值正規化至 -1 dBFS。 | 訓練 SVC / RVC 歌手模型、取樣機音色採集。 |

## 4. 第四步：19+ 階層式分軌樹 (DAG) 與自訂組合

### 4.1 一鍵預設按鈕
上方提供 7 組常用的分軌組合：
* **全選 18 軌**：分離全部樂器。
* **人聲極致 5 軌**：主唱乾音、主唱殘響、和聲乾音、和聲殘響、人聲氣音喘息。
* **DrumSep 鼓組 6 軌**：大鼓 (Kick)、小鼓 (Snare)、通鼓 (Toms)、腳踏鈸 (Hi-Hat)、疊音鈸 (Ride)、碎音鈸/吊鈸 (Crash)。
* **節奏組**：鼓組全套 + 電貝斯。
* **吉他/管弦細分**：木/電吉他、平台鋼琴、合成器、管弦樂。
* **KTV 伴唱 (去主唱)**：自動取消主唱，保留完整高品質伴奏。

### 4.2 自訂組合保存
勾選想要的分軌後，點擊 **「+ 儲存自訂組合」**，輸入名稱（例如：`主唱+吉他`），即可產生專屬快捷按鈕。

### 4.3 AudioSep 自然語言抽離
若音樂中有特殊樂器，可在下方輸入英文名稱（例如：`flute`, `violin`, `saxophone`, `cello`），點擊「+ 新增」，系統將自動從伴奏中精準抽離該樂器！

## 5. 第五步：WebAudio 多軌 DAW 混音台操作

* **[S] Solo (獨奏)**：點擊變綠，僅播放該軌（支援多軌同時 Solo）。
* **[M] Mute (靜音)**：點擊變紅，該軌即刻靜音。
* **[Ø] Invert (反相)**：單軌 180° 相位翻轉。
* **音量推桿 (Volume)**：可向下衰減至靜音，或向上增益至 +3.5 dB。
* **立體聲 Pan**：左聲道 (L) ~ 右聲道 (R) 聲相擺位。
* **動態波形畫布**：高解析度峰值波形，點擊任意位置時間軸立即同步跳轉。
* **☑️ 全選 / ⬜ 全清**：位於混音台工具列最左端，垂直對齊音軌勾選框，一鍵打勾或清空勾選。

### Ø 反相抵消測試 (Null Test)
點擊主控台上方 **`Ø 反相抵消測試 (Null Test: OFF/ON)`**：
所有已載入音軌會與未分軌的原曲反相疊加播放。
* 顯示 **`Null 誤差: -130.5 dBFS`**，代表反相後完全無聲，證明數學級的完美無損！

## 6. 第六步：非破壞性片段剪輯與局部消音工坊 (v2.0 新增)

在 Master Transport 控制列中央，配備了 4 顆專業級的編曲剪輯按鈕：

```text
[ 🖐️ 選取 (1) ]  [ ✂️ 剪刀 (2) ]  [ 🔇 片段消音 (3) ]  [ ⟲ 重置剪輯 ]
```

### 6.1 ✂️ 剪刀切分模式 (快速鍵: 2)
1. 點擊「✂️ 剪刀」按鈕或按下鍵盤 **`2`**。
2. 滑鼠游標移至任何分軌的波形畫布上，游標會變為剪刀樣式。
3. 在任意想要切開的時間點單擊滑鼠左鍵，系統立即在該處產生一條剪切虛線，將音訊波形分割為多個獨立片段。

### 6.2 🔇 片段消音模式 (快速鍵: 3)
1. 點擊「🔇 片段消音」按鈕或按下鍵盤 **`3`**。
2. 游標移至任意已切分的片段上。
3. 單擊滑鼠左鍵，該片段立即被加上**半透明斜紋灰遮罩**，代表該片段已進入局部消音狀態。
4. 播放頭經過該消音片段時，WebAudio 引擎會自動零延遲靜音；再次點擊同一片段即可立即恢復發聲。
5. **合併匯出（WAV / MP3）時自動遵守所有消音片段**，實現專業級非破壞性段落編輯！

### 6.3 ⟲ 重置剪輯
* 點擊「⟲ 重置剪輯」按鈕，即可將所有軌道的切分斷點與局部消音設定全部清空，恢復為完整原軌。

* 系統立即在後端建立全新的獨立專案記錄，自動共享底層音訊快取不佔額外磁碟空間，並完整封存當前的消音片段設定。

## 8. 第八步：原曲調性辨識與多軌神經變調變速

### 8.1 自動調性分析徽章
* **原調徽章**：當歌曲分軌載入後，系統自動顯示 AI 偵測結果（例如：`原調: D 大調 (D Major)`）。
* **目標調性預覽**：拉動升降桿時，目標調性徽章即時換算新調（例如：`目標: G 大調 (G Major) [-5]`）。

### 8.2 升降半音與分治變調邏輯
1. **拉桿平滑預覽**：
   - 透過「`-1` / `+1`」步進按鈕或中央滑桿，在 **$-6 \sim +6$ 半音** 之間自由挑選。
2. **點擊「⚡ 套用變調」正式執行**：
   - 點擊按鈕後混音台進入變暗遮罩保護模式。
   - **鼓組軌道 100% Bypass**：自動保留原始衝擊力道，零失真。
   - **人聲與伴奏樂器**：4 執行緒平行運算，鎖定共振峰，絕無機器電音雜質。
3. **一鍵恢復原調**：點擊「`⟲ 恢復原調`」即可 0 秒重置回原調。

### 8.3 時間軸拍速調整 (BPM)
* 透過拍速拉桿可自由在 50 ~ 220 BPM 之間調整，點擊「⚡ 套用新拍速」即可實現變速不變調的無損時間拉伸。

## 11. 常見問題與疑難排解 (FAQ)

### Q1：消音片段另存新專案後，重新載入會保留消音設定嗎？
* **完全會！** v2.0 專案持久化引擎會在另存新專案時，將所有軌道的裁切斷點與局部消音片段（`muted: true`）完整序列化至 `project_state.json`，重新載入 100% 完整還原。

### Q2：上傳 MP4 影片時提示 FFmpeg 錯誤？
* 請確認本機已安裝 FFmpeg（例如放在 `C:\Program Files\ffmpeg\bin\ffmpeg.exe`）並已設定好 PATH 環境變數。工作站頂部若顯示綠燈即代表 FFmpeg 連線正常。

### Q3：電腦沒有 NVIDIA 獨立顯卡能用嗎？
* 完全可以！若無 CUDA 顯卡，系統會自動切換至純 C# SIMD 多核心 DSP 頻譜分離引擎，所有 Windows 10/11 電腦皆可使用。
